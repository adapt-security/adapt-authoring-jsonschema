# adapt-authoring-jsonschema

Adds JSON Schema support to the Adapt authoring tool. A thin wrapper around the `adapt-schemas` library providing application integration — hooks, logging, configuration and error handling — so other modules can register and validate against schemas.

Extends `AbstractModule` from [adapt-authoring-core](../adapt-authoring-core).
